What PocketSage Is

An iOS and Android app where you chat with a local LLM that can do things — check your calendar, set reminders, read health data, search files and contacts. The model runs on your phone via ExecuTorch. Conversations and memories stay in a local vector database. Zero bytes leave the device.

🧠

On-Device LLM

Llama 3.2 1B/3B SpinQuant runs locally via ExecuTorch. SHA-256 verified downloads from HuggingFace.

SpinQuant (ICLR 2025)

🔧

Tool-Calling Agent

ReAct-pattern loop: reason → act → observe. Calendar, reminders, health, files, contacts. SKILL.md-compatible.

ReAct (ICLR 2023)

💾

RAG Memory

Conversations chunked, embedded, and stored in a local vector database. Cross-session recall via GLOBAL.md.

react-native-rag (Software Mansion)

🔒

Provably Private

Zero network calls during inference. Revoke network permission after model download — the agent still works.

ACM Computing Surveys (2025)

iOS and Android from one codebase. Expo SDK 57, React Native 0.86, NativeWind dark theme.
